# 问卷星答题配置助手（增强版）

> Tampermonkey 用户脚本 · 问卷星填写辅助工具

针对问卷星的**可视化配置型填写助手**：自动识别常见题型，按**比例**或**次数**配置答案，支持评分星级、关联题、多页填写、预览高亮、配置导入导出与失败恢复。

基于原版二次开发（原脚本见 [ScriptCat](https://scriptcat.org/zh-CN/script-show-page/6321) / [GreasyFork](https://greasyfork.org/zh-CN/scripts/569375)），UI 重构为可视化面板。

---

## 功能特性

### 题型支持
- 单选 / 多选 / 下拉选择
- 填空题（含多字段按类型生成）
- 评分星级
- 矩阵题
- 地区选择
- 排序题
- 占比题（按题目合计值分配，自动补齐取整误差）
- 滑块题
- 文本答案

### 配置能力
- **双模式**：按比例分配 / 按数量分配
- **关联题联动**：子题随父题选项联动扫描
- 多页自动翻页
- 题目搜索与题型筛选
- 配置**导入 / 导出**（JSON）
- 面板**拖拽**并记忆位置
- 速度配置（慢速 / 正常 / 快速）

### 自动化会话
- 预览填写 / 答案高亮 / 填写到提交
- 暂停 / 继续 / 跳过 / 停止
- 失败恢复与配额回滚
- 进度实时反馈

### 资源与反馈
- 面板内提供 [星夜题库](https://tiku888.top/) 资源入口：千万免费题库，支持 OCS 网课助手接入与配置
- [OCS 接入说明](https://tiku888.top/guide) 可在新标签页查看
- 标题栏提供 QQ 群反馈入口，便于提交使用问题与建议

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）
2. 打开脚本原始地址：`https://raw.githubusercontent.com/3975741474/wjx-survey-automation/main/问卷星.js`，或访问本仓库页面复制脚本内容
3. Tampermonkey 会提示安装，点击确认即可

**匹配域名**：`*.wjx.top` · `*.wjx.cn` · `*.wjx.com`

---

## 使用

1. 打开任意问卷星问卷页面，右下角出现脚本面板
2. 在面板中配置各题型的答案分配（比例或数量）
3. 点击「填写」或「预览」执行

---

## 配置说明

| 配置项 | 说明 |
|---|---|
| 分配模式 | 比例（按权重随机）或数量（按次数逐一分配） |
| 速度 | 慢速 / 正常 / 快速，控制填写与翻页节奏 |
| 预览 | 只高亮所选答案，不实际提交 |
| 填写到提交 | 自动填写全部题目并提交 |

---

## 风险提示

> ⚠️ 本脚本包含**自动批量提交**与**模拟交互**能力，自动提交可能触发问卷星平台风控，生成式随机答案也可能造成低质量或重复的回答。**请仅在获得授权的问卷中使用**，遵守问卷发起方与平台的使用条款。

|---|---|
| 0.1.15 | 新增占比题（`type=12`）支持：此前该题型被兜底识别成填空题，填充词库文本导致提交被拦；现在按行内 `input[issum="1"]` 精确识别、读出题目 `total` 作为合计目标、按配置权重分配并把取整误差补到最大项，同时同步 `rangeslider` 视觉位置，面板显示「占比题 / N 个占比项，合计 100」，题型筛选新增占比题。同时修复带封面页的问卷「多一步进入」：封面入口 `#slideChunk` 既不是 `a`/`button` 也没有 `onclick`，此前不在可见按钮候选里，导致预览与自动化报「未识别到题目页或开始按钮」；现在优先识别封面入口并用原生 `click` 事件点击（兼容 `coverEffect_new.js` 的 jQuery 委托）后再等题目页出现 |
| 0.1.14 | 风控识别与自我保护：连续 2 次提交后仍未通过人机验证时，不再继续空撞，而是自动暂停并提示「疑似当前网络环境已被问卷星风控，建议更换网络后继续或等待冷却」，避免把风控等级撞得更高；「设计份数」输入框下方新增份数建议提示，超过 100 份时用醒目样式提醒分批执行；「清除本地数据」按钮扩展为同时清理问卷星的作答残留（`wjxanswerdata`、`wjxgguid` 等）与脚本可写的设备标识 Cookie（`uuuvid`、`_c_WBKFRo`、`jac*`、`SERVERID`），并在提示中给出换网络与冷却引导 |
| 0.1.13 | 修复手机版（`v.wjx.cn`）矩阵题填不上：手机版矩阵数据行没有标题列，旧逻辑无条件跳过首列并依赖「行文本非空」判定数据行，导致 6 行全部被跳过、表头行反被当成数据行点击，提交时提示「请回答此题」；现在按 `tr[rowindex]` 精确取数据行、排除表头/分组行，并按是否存在标题列决定是否跳过首列。同时缓解快速档提交被拦：快速档压缩系数由 `0.68` 放宽到 `0.85`，并为快速档加上操作与提交前等待的绝对下限 |
| 0.1.12 | 修复排序题（type=11）间歇性漏填：预览填写入口未复位上一轮自动化留下的停止标志，导致 `fillSorting` 按 `isAutomationInterrupted` 提前退出而静默跳过；现在预览入口会重置该标志，且排序题只在本题执行期间新出现的中断才收手 |
