## 3. GitHub 独立竞品

### 3.1 MingNin9466 / survey-autofill-helper

| 项 | 值 |
|---|---|
| 版本 / 许可 | 1.0.2 / MIT |
| Star / Fork | 2 / 0 |
| 创建 / 推送 | 2026-10-22 / 2026-10-22 |
| 代码量 | 1,728 行 |
| 覆盖站点 | 9 个：wjx.cn / wjx.top / sojump.com / wj.qq.com / f.wps.cn / jinshuju.net / wenjuan.com / mikecrm.com / jsform.com |
| 设计定位 | **只填不交**：绝不调用 `submit`，也不点提交按钮 |

**架构**：适配器模式 `ADAPTERS = [wjxAdapter, qqAdapter, wpsAdapter, genericAdapter]`，每个适配器有 `id` / `match(host)` / `scan()`。这是四个项目里**唯一有正式多站点抽象**的实现。

**问卷星适配器**（648–714 行）：
- 选择器 `$$('#divQuestion div.field, div.field.ui-field-contain')`
- 题号取 `topic` 或 `field.id`
- 单选/多选分别用 `a.jqradio` / `a.jqcheckbox`
- **矩阵/表格题显式标为 `unsupported: '矩阵/表格题暂不支持，请手动填写'`**

**短板**：
- 题型覆盖窄于本项目：矩阵不支持、无排序、无占比、无填空组、无地区题、无滑块。
- 无「按比例/次数配置」这种统计意图的表达能力 —— 它是「模板回填」而非「可控分布采样」。
- 填写协议同样只派发 `input`/`change`（未处理 `keyup`/`blur` 链路）。

**值得借鉴**：`unsupported` 字段 + 面板提示「请手动填写」的做法，与本项目 `pickerBased` 的处理思路一致，方向正确。

### 3.2 DreamYuande / wjx-question-bank-collector

| 项 | 值 |
|---|---|
| 版本 / 许可 | 2.0.1 / MIT |
| Star / Fork | 0 / 0 |
| 创建 / 推送 | 2026-10-25 / 2026-10-25 |
| 代码量 | 424 行 |
| URL 约束 | 仅 `/vm/<id>.aspx` 与 `/vj/<id>.aspx` |

**定位完全不同**：题库**采集**器，不是填写器。识别单选/多选/判断，支持定时刷新采集、Excel/JSON/CSV/文本四格式导出，内置手写 XLSX 生成器（自带 styles/theme 模板，无外部库）。

**题型判据**：
```js
if (field.getAttribute('type') === '4') return '多选题';
const hint = clean(field.querySelector('.qtypetip')?.textContent) + sectionOf(field);
if (/判断/.test(hint)) return '判断题';
if (/正确|错误|对|错|true|false|×|√/.test(pair)) return '判断题';
return '单选题';
```
即：**用 `.qtypetip` 文案 + 选项对特征**判判断题，而非仅靠 `type`。这是一个本项目没有覆盖的角度（WJX 判断题通常也是 `type=3`）。

**短板**：明确只支持 `type` 3/4；填空题、矩阵题标注「暂不支持」。

**值得借鉴**：`.qtypetip` 文案识别判断题。本项目目前把所有 `type=3` 一律标为「单选题」，若问卷含判断题，面板标签会不精确（虽不影响填写正确性）。

## 5. 差异化结论

1. **填写正确性的深度是最大壁垒。** 只有本项目系统比对了 WJX 前端脚本的**事件绑定契约**（`keyup blur click`、`blur keyup`、`rate-off→rate-on`），并据此修正写入序列。上游即便 4.1.4 仍停留在 `input`/`change`。
2. **"可控分布"是独有能力。** 其余三家要么固定模板回填（MingNin9466）、要么只采集（DreamYuande）、要么只有粗粒度权重（上游）。本项目的比例/次数双模式 + 占比题 `total` 约束 + 关联题联动重扫，是唯一能表达「我要 30% 选 A」的实现。
3. **上游已停更。** GreasyFork 最后更新 2026-03-13；ScriptCat 条目自述「后续不会更新」。分化只会继续扩大。
4. **多站点是别人更强的地方。** MingNin9466 的适配器模式覆盖 9 个平台，本项目只做问卷星。这是刻意的取舍（做深一个 vs 做广多个），不宜盲目追平。
5. **判断题标签可补。** DreamYuande 用 `.qtypetip` 文案识别判断题，成本极低，可提升面板显示精度。
